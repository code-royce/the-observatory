# The Observatory

This directory contains the frontend of The Observatory AKA "Light Pollution
Analytics and Celestial Visibility Planner".

## Local Development
Requirements: Node.js >=24.0.0 (or latest LTS, whichever is newer) with npm

1. `npm install` from *this* directory.
2. `npm run dev` builds a local dev-only version of the site.
3. Please run `npm run build` before pushing your changes to the repo.
4. Preview the built app with `npm run preview`.
